# SquirrelStock: настройка и работа

Руководство для организации, которая бесплатно выдаёт расходные материалы и оборудование получателям (подопечным, семьям, учреждениям). Всё ниже проверено на Docker-стенде из этого репозитория; установка на Windows пока не описана и не проверялась.

## Установка (Docker)

```bash
git clone https://github.com/likemusic/squirrel-stock.git && cd squirrel-stock/docker
SQS_LANG=ru docker compose up -d --build      # http://127.0.0.1:8083, вход admin / admin
```

При первом запуске база создаётся из `db/db.sql` (база Zippy) и `db/squirrelstock.sql` (отчёты и страницы SquirrelStock в меню). На уже существующей базе `db/squirrelstock.sql` выполняется вручную, повторный запуск безопасен.

Сразу после входа смените пароль администратора в профиле.

## Начальная настройка

1. **Профиль для благотворительной организации** — оставляет в меню нужное для выдачи (около 30 пунктов из 90) и выставляет настройки: учёт по серийным номерам, запрет минусовых остатков, цена выдачи 0.

   ```bash
   docker exec squirrelstock-web-1 php cli/charity-profile.php
   ```

   Вернуть выключенные пункты меню: тот же скрипт с `--back` или «Система → Настройка меню».

2. **Русские названия в базе.** Тексты интерфейса переводятся словарём, а названия документов, пунктов меню, основного склада и кассы лежат в базе на украинском. Перевести их один раз:

   ```bash
   docker exec squirrelstock-web-1 php cli/localize-db.php ru
   ```

   После обоих скриптов войдите в программу заново: настройки кэшируются в сессии.

3. **Язык** выбирается в профиле пользователя («Язык интерфейса»), по умолчанию — из `config.php` (в Docker — переменная `SQS_LANG`).

4. **Сумма прописью** в печатных формах: «Настройки → Общие → Валюта суммы прописью» — рубль, гривна, доллар или евро.

5. **Склады для состояний оборудования:** «Справочники → Склады» — добавьте склады «Ремонт» и «К списанию». Единица, перемещённая на такой склад документом «Перемещение ТМЦ», показывается в отчёте об оборудовании с этим состоянием.

6. **Категории товаров**, например «Расходные материалы», «Оборудование» и отдельная группа, по которой нужен отдельный учёт (у хосписа — гастростомы). По категориям отбираются отчёты и составляются отдельные акты.

## Номенклатура и остатки из 1С

«Сервис → Импорт ведомости 1С» читает оборотно-сальдовую ведомость 1С (.xls, .xlsx):

- по счёту 10 (материалы) — позиции и остатки: позиция ищется по точному названию или создаётся, остаток приходуется по цене «сумма / количество»;
- по счёту 01 (основные средства) — единицы оборудования: товар создаётся с учётом по серийным номерам, каждая единица приходуется со своим инвентарным номером.

Названия остаются как в 1С, чтобы бухгалтерия могла сопоставить акты. Документ прихода создаётся на дату из формы. Повторный импорт не дублирует единицы с инвентарными номерами, а материалы приходует ещё раз.

## Получатели

Получатель — контрагент в «Справочники → Контрагенты». Признаки получателя («подопечный», «по запросу», «организация», «снят с опеки», группа вроде «гастростома») задаются тегами контрагента; по тегу работает отбор в списке контрагентов и в отчёте «Получатели по месяцам». Справочник проверен на 5 000 контрагентах: список открывается за секунду, подсказка в документе — за доли секунды.

## Расходные материалы

- Поступление — «Приходная накладная» (от донора или поставщика) или «Оприходование ТМЦ».
- Выдача получателю — «Расходная накладная» по цене 0.
- Возврат от получателя — «Возврат от покупателя», создаётся на основании выдачи.
- Списание (порча, истёк срок, брак) — «Списание ТМЦ», причина пишется в примечании.

Повторное нажатие «Провести» на проведённом документе и кнопка «Назад» в браузере после проведения больше не удваивают остатки: программа отказывается проводить документ второй раз. Чтобы изменить проведённый документ, сначала отмените проведение в журнале.

## Оборудование

Каждая единица — товар с учётом по серийным номерам, номер — инвентарный. Мелкое оборудование без номера ведите обычным товаром (без флажка серийного учёта), количеством.

1. **Договор:** «Справочники → Договоры» → «Добавить»: номер (например «234/26»), дата, получатель, дата окончания (срок пользования; «до востребования» — дата 31.12.2099), в «Кратком описании» — кем направлен. Затем откройте договор и переведите его в состояние «В работе» — только такие договоры выбираются в документах.
2. **Выдача:** «Расходная накладная» на получателя, в поле «Договор» — этот договор, в строке — инвентарный номер единицы.
3. **Возврат:** «Возврат от покупателя» на основании выдачи.
4. **Ремонт и списание:** «Перемещение ТМЦ» единицы на склад «Ремонт» или «К списанию»; окончательное списание — «Списание ТМЦ».

Два взгляда на одни и те же данные:

- «Отчёты → Склад → Оборудование: где сейчас» — каждая единица: на каком складе или у какого получателя, с телефоном, адресом, договором и сроком; просроченный срок выделен красным; поиск по модели, номеру или получателю; над списком — итог по моделям: сколько выдано, на каждом складе («Ремонт», «К списанию»), списано, всего;
- «Отчёты → Склад → Журнал выдачи оборудования» — все выдачи за период с датами возврата.

### Перенос истории выдач из таблиц

«Сервис → Импорт истории выдачи оборудования» переносит историю из Google-таблиц «Перепись оборудования» и «Журнал выдачи оборудования» (скачать каждую как .xlsx: «Файл → Скачать → Microsoft Excel»).

Порядок:

1. Сначала загрузите единицы из 1С: «Сервис → Импорт ведомости 1С», ведомость по счёту 01. Единица с инвентарным номером, которой нет в базе, не импортируется — она попадёт в отчёт со списком недостающих номеров.
2. Потом историю: выберите оба файла и нажмите «Проверить». Ничего не записывается; показывается, что будет создано (получатели, договоры, выдачи, возвраты, списания), ошибки — строки, которые не импортируются (текст вместо даты, несколько единиц в ячейке, «вернули» без даты и т. п.), и заметки — что импортировано с допущением. Исправьте что можно в таблицах и проверьте снова.
3. «Записать». История старше начала актуального периода из настроек (по умолчанию 1 января текущего года), а документы раньше этой даты программа не сохраняет. Отметьте «На время записи снять ограничение закрытого периода»: начало периода временно переносится на дату самой ранней записи и возвращается после записи, даже если она прервалась; что стояло и что вернули — в результате импорта и в журнале программы. Без отметки запись откажет с объяснением.

Одна выдача, записанная в обеих таблицах, импортируется один раз. Повторный импорт тех же файлов не дублирует уже перенесённое, а добавляет новое (например, вписанную потом дату возврата).

## Отчёты

- **Акт списания за месяц** — в формате бухгалтерии: строки — позиции, колонки — выдачи «Получатель дд.мм.гггг», итоги; возвраты вычитаются. Отбор по категории (отдельные акты на расходники и оборудование), выгрузка в Excel.
- **Получатели по месяцам** — кто в каком месяце получал: отметка «х», количество или число выдач; отбор по категории, позиции и тегу получателя.
- **Оборот по позициям** — на начало, приход, выдано, возвращено, списано, прочее, на конец, число выдач; с отбором по получателю — что ему выдано за период.
- **Ниже минимального остатка** — список для закупки: позиции, у которых остаток меньше «Мин. количества» из карточки позиции (справочник номенклатуры), сколько не хватает до минимума, последнее поступление и от кого. В списке и позиции, которых на складе ещё не было. Отбор по складу и категории, выгрузка в Excel.
- Штатные отчёты Zippy: «Состояние складов», «Движение по складу», «Закупки».

## Резервная копия

«Сервис → Резервная копия» → «Создать копию» скачивает zip с базой и прикреплёнными файлами. Делайте копию каждый день в конце работы и храните не на этом компьютере. Восстановление — там же, с подтверждением: текущие данные заменяются данными из копии. Файл `database.sql` из архива загружается и обычным клиентом `mysql`.

Автоматическая копия по расписанию — в папку на этом компьютере, в сетевую папку и в облако (зашифрованной), с предупреждением, если копии давно не было: настройка и расписание — [BACKUP.ru.md](BACKUP.ru.md).

## Без интернета

Программа не обращается к внешним адресам: графики рисуются локальной библиотекой, проверка обновлений Zippy с сайта автора отключена. Проверено на стенде без выхода в сеть (`docker/docker-compose.offline.yml`).
