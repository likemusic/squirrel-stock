# Документация SquirrelStock

Что это за программа — [README.md](../README.md) в корне репозитория (English: [README.en.md](../README.en.md)).

## Работнику склада

- [USER_GUIDE.ru.md](USER_GUIDE.ru.md) — как выдать расходники и оборудование, принять возврат, списать, оприходовать, найти ответ в отчётах, продлить срок, сделать резервную копию, включить двухфакторный вход. Со снимками экрана.

## Тому, кто настраивает программу

- [GUIDE.ru.md](GUIDE.ru.md) — начальная настройка (профиль для благотворительной организации, русские названия, склады, категории), получатели, перенос остатков из 1С и истории выдач из таблиц, что умеют отчёты, вход и защита, демо-база.
- [BACKUP.ru.md](BACKUP.ru.md) — автоматическая резервная копия: места, расписание (Windows, cron, systemd, Docker), облака через rclone, восстановление.

## Администратору: установка и обновление

- [INSTALL_LINUX.ru.md](INSTALL_LINUX.ru.md) — Debian 12 и Ubuntu 24.04 одним скриптом: отдельный компьютер на складе или VPS.
- [INSTALL_HOSTING.ru.md](INSTALL_HOSTING.ru.md) — хостинг с Apache (ISPmanager): пакет, база, файлы, защита, проверка сайта `check-site.sh`.
- [INSTALL_WINDOWS.ru.md](INSTALL_WINDOWS.ru.md) — Windows 10 и 11 на складе: Apache, PHP и MariaDB службами Windows, копия через Планировщик, доступ с телефонов, проверка `check-windows.ps1`.
- [UPDATE.ru.md](UPDATE.ru.md) — обновление программы до новой версии.

## Разработчику (на английском)

- [DEVELOPMENT.md](DEVELOPMENT.md) — стенд Docker, автотесты, переводы, устройство кода.
- [MODULES.md](MODULES.md) — модули и точки расширения: как добавить свой документ, отчёт или проверку без правки кода Zippy.
- [CORE_CHANGES.md](CORE_CHANGES.md) — каждая правка кода Zippy с тестом; нужен при обновлении из исходного проекта.

Пометки «[проверено]» и «[не проверено]» в документах значат: пройдено на практике или описано по коду и документации.
